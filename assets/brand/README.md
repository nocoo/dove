# Dove identity

The adopted animal keeps the previous character, expression, palette, and signature details. Its lower anatomy continues naturally to the square boundary. Eyes, ears, horns, blossoms, and crown details remain inside the checked rounded-square safe area.

- `src/client/public/logo.png` is the transparent 2048 × 2048 master.
- `assets/brand/icon.png` is the square presentation for icons masked by the platform.
- `assets/brand/icon-rounded.png` supplies its own rounded corners for the README and application surfaces.

Use `uv run --with pillow python scripts/resize-logos.py` to regenerate application assets. The script verifies master dimensions, alpha roles, and embedded favicon resolutions.

[Individual comparison and downloads](https://hexly.ai/logos/dove) · [Complete generation and finishing archive](https://github.com/nocoo/hexly.ai/tree/main/artwork/logo-family/dove/2026-09-07-02)

`provenance.json` records the raw generation, selected finishing pass, previous identity, exact adopted hashes, and delegated review scope. Presentation colors remain separate from website theme tokens.
